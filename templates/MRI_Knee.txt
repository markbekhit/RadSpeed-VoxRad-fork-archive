### Comparison:
**Instructions:**

### Findings:
**Instructions:**
- Describe pathological structures specifically. Normal structures within the same anatomical group may be combined into a single statement — do not force a separate bullet for every structure when all are normal.
- Cover all groups in the order shown in the structure section.
- Use precise radiology terminology for normal structures:
  - Menisci → "intact"
  - Ligaments → "intact"
  - Tendons → "intact"
  - Articular cartilage → "intact, no focal chondral defect"
  - Joint effusion → "no joint effusion"
  - Baker's cyst → "no Baker's cyst identified"
  - Bony structures → "no fracture or aggressive bony lesion"
  - Bone marrow → "no bone marrow oedema"
  - Soft tissues → "unremarkable"
- Cruciate Ligaments: describe ACL and PCL individually if pathology; otherwise a single combined statement is acceptable.
- Collateral Ligaments and Posterolateral Corner: describe individually if pathology; otherwise combine normals.
- Articular Cartilage: if all surfaces are intact, a single statement suffices ("Articular cartilage intact throughout, no focal chondral defect."). If pathology is present, report by compartment (medial, lateral, patellofemoral). Patellofemoral alignment and tracking are included here; do not create a separate Patellofemoral Joint heading.
- Tendons: combine quadriceps and patellar tendons if both normal.
- Bony Structures: ALWAYS use the radiologist's exact dictated words for bony/marrow findings, whether normal or abnormal. Examples:

  - If they said "normal bony alignment, no marrow signal abnormality" → write exactly that.
  - Only use the default "Bone marrow signal is normal. No suspicious osseous lesion identified." if the radiologist said NOTHING about bony structures.
  - If a specific abnormality is described, state it, then add "Remaining marrow signal is normal."

### Impression:
**Instructions:**
- Concise bullet-point summary of key findings.
- After positive findings, use one supported pertinent-negative point: 'Intact cruciate, collateral ligaments and menisci.' Adjust this to name only the remaining confirmed intact structures when an injury is already described. Exclude injured, sprained, partially torn, uncertain or unassessed structures. Do not repeat the injury or infer intact structures from silence.
- Use a comma after 'cruciate' and only one 'and' before the final structure. For a medial meniscal tear, use 'Intact cruciate, collateral ligaments and lateral meniscus.' Do not write 'cruciate and collateral ligaments and lateral meniscus'.
- Include only clinically relevant findings. Minor incidental findings that are fully described in the body do not need to be restated here.
- Keep isolated low-grade meniscal free-edge fraying, degenerative signal and intrasubstance signal in the Findings only when there is no definite tear. Include a definite meniscal tear, displaced fragment, root injury, extrusion or parameniscal cyst. Preserve minor fraying only if the radiologist explicitly dictates that it is clinically important.
- For a normal/negative study, include a closing statement where appropriate, e.g. 'No cause for the patient's symptoms identified on this examination.'
